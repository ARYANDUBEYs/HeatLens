## PHASE 1: CORE AZURE SERVICES TO INTEGRATE (Priority Order)
=============================================================

### 1. Azure OpenAI Service (GPT-4o)
   PURPOSE : Natural language interface for heat map queries
   WHAT IT DOES:
     - User types: "Show me the 10 hottest wards in Delhi in July 2025"
     - Azure OpenAI parses intent → triggers satellite data query → returns visual map
   IMPLEMENTATION:
     - Use Azure OpenAI REST API with function calling
     - Functions: get_ward_lst(ward_name), get_heat_ranking(date), compare_wards(list)
     - Model: gpt-4o or gpt-4o-mini (cheaper for demo)
   COST: ~$5-10/month for demo usage
   JUDGE IMPACT: Very High ⭐⭐⭐⭐⭐

### 2. Azure Maps (Replace Leaflet.js)
   PURPOSE : Professional-grade geospatial visualization
   WHAT IT DOES:
     - Render ward-level heat vulnerability choropleth maps
     - Overlay satellite thermal raster on Azure Maps tiles
     - Enable ward boundary polygon rendering with heat score colors
   IMPLEMENTATION:
     - npm install azure-maps-control
     - Replace Leaflet map initialization with Azure Maps Atlas control
     - Use azure-maps-drawing-tools for interactive ward selection
   COST: Free tier (25,000 map loads/month)
   JUDGE IMPACT: Very High ⭐⭐⭐⭐⭐

### 3. Azure Blob Storage
   PURPOSE : Store satellite raster files (GeoTIFF, PNG tiles)
   WHAT IT DOES:
     - Replace Hugging Face Spaces file storage
     - Store pre-processed LST rasters per city per month
     - Serve via Azure CDN for <20ms global latency
   IMPLEMENTATION:
     - az storage account create
     - Upload GeoTIFF files via Azure Storage SDK (Python)
     - Generate SAS tokens for public read access
   COST: ~$0.018/GB/month (negligible for demo)
   JUDGE IMPACT: Medium ⭐⭐⭐

### 4. Azure AI Vision (Custom Vision / Image Analysis)
   PURPOSE : Satellite image classification and anomaly detection
   WHAT IT DOES:
     - Classify land use from Sentinel-2 imagery (vegetation vs concrete vs water)
     - Detect urban heat island "hotspots" as image regions
   IMPLEMENTATION:
     - Use Azure Computer Vision 4.0 API for image segmentation
     - OR train Custom Vision model on labeled satellite patches
   COST: Free tier (5,000 calls/month)
   JUDGE IMPACT: High ⭐⭐⭐⭐

### 5. Azure Functions (Serverless Pipeline)
   PURPOSE : Replace current FastAPI endpoints with serverless compute
   WHAT IT DOES:
     - Trigger satellite data ingestion on schedule (weekly LST updates)
     - Process new Landsat scenes automatically when available
     - HTTP trigger for on-demand ward analysis requests
   IMPLEMENTATION:
     - func init HeatLens --python
     - func new --name SatelliteIngestTrigger --template "Timer trigger"
   COST: Free tier (1M executions/month)
   JUDGE IMPACT: High ⭐⭐⭐⭐
